# Sinthos Inc

A responsive company website positioning Sinthos as a defense technology company. Passive acoustic detection is presented as its first development program.

## Run

Requires Node.js 20.11+ (or later) and Python 3 for the local preview. There are no npm dependencies.

```sh
npm run build
npm start
```

Open http://127.0.0.1:4173 . The complete public website is in `dist/`; serve it with any static web server.

## Included

- Original identity and favicon, self-hosted open fonts, generated landscape asset.
- Responsive landing page, keyboard-operable mobile navigation, explanatory sound-field canvas, three accessible workflow tabs, animation pause, reduced-motion support.
- Contact email and copy button. No analytics, cookies, contact-form backend or trackers.
- Program status and research sources; no fabricated performance numbers, customers, certifications, field deployments or funding.
- DESIGN.md records research, design tokens, content choices and asset provenance.

## Editorial choices

The founder's name-origin explanation is intentionally absent from the public page. The company mission precedes the first program. The visual is an illustrative operating landscape, not a claim about a field trial or location. The acoustic visualization is a conceptual explanation, not a functioning detector or live telemetry.

## Editing

Content: index.html. Core styling: styles.css. Section styling: sections.css. Behaviors and conceptual animation: app.js. Contact: subhro@sinthosinc.com.

Do not add detection range, accuracy, deployments, partners, or hardware renders without evidence. Replace development language when actual milestones have been completed.
